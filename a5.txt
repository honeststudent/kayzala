# Nikto Practical - Quick Commands (for Exam)

# Step 1 - Install Nikto
sudo apt update
sudo apt install nikto -y

# Verify installation
nikto -h

# Step 2 - Basic scan on test website (safe target)
nikto -h http://testphp.vulnweb.com

# Step 3 - Scan SSL/HTTPS website
nikto -h https://pbs.org -ssl

# Step 4 - Network discovery with Nmap (find subnet first)
sudo ifconfig
# Example: scan port 80 on local subnet and save output
sudo nmap -p 80 10.0.2.0/24 -oG myscan.txt

# Optional: view saved scan results
cat myscan.txt

# Step 5 - Install and start Apache locally (if no host has port 80 open)
sudo apt install apache2 -y
sudo service apache2 start

# Step 6 - Scan local Apache server with Nikto
nikto -h http://127.0.0.1

# Optional: save Nikto output to a file
nikto -h http://127.0.0.1 -o nikto_local_report.txt

# Optional: verbose output
nikto -h http://127.0.0.1 -v

Network Scanning Using Nikto
What is Nikto?
Nikto is an open-source web server vulnerability scanner written in Perl. It is widely used in
penetration testing and security assessments to scan web servers for potential security issues.
Nikto checks for:
• Over 7,000+ potentially dangerous files and programs
• Outdated versions of over 1,250 servers
• Configuration issues (like multiple index files, insecure HTTP headers)
• SSL/TLS related vulnerabilities
• Use of default files and weak configurations
Nikto is not a stealthy tool; it is designed to be fast and comprehensive, making it useful for
administrators and security testers to quickly identify weaknesses.
Features of Nikto
• Scans web servers for outdated software and known vulnerabilities.
• Detects missing HTTP security headers such as X-Frame-Options or X-Content-TypeOptions.
• Identifies dangerous files, backdoors, and misconfigured scripts.
• Supports SSL/TLS scanning (-ssl flag).
• Can take Nmap results as input to focus on live hosts with HTTP services.
• Saves results in multiple formats (TXT, CSV, HTML, XML).
• Open source and frequently updated.
Why Use Nikto?
Web servers are one of the most targeted components of a network. Misconfigurations, old
software versions, or insecure practices can lead to severe vulnerabilities. Nikto provides:
• A quick way to enumerate server details.
• Identification of potential exploits and insecure headers.
• A baseline for further manual penetration testing.
Role of Nmap with Nikto
• Nmap is used for network discovery to find live hosts and open ports (such as port 80
for HTTP).
• Nikto is then used to perform in-depth vulnerability scanning of the identified web
services.
• Together, they provide a practical approach to network scanning: discovery first
(Nmap), detailed analysis second (Nikto).
