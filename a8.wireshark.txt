------------------------------------------------------------
BASIC COMMANDS (use in terminal)
------------------------------------------------------------

1. Check Wireshark version
   wireshark --version

2. Allow non-root capture permissions
   sudo usermod -aG wireshark $USER
   (then logout and log back in, or reboot)

3. Launch Wireshark
   wireshark &

------------------------------------------------------------
NETWORK CAPTURE STEPS
------------------------------------------------------------

1. Open Wireshark and select your active interface (for example, eth0 or wlan0)
2. Start packet capture (double-click the interface)
3. Open Firefox and visit:
   https://chat.openai.com
4. Observe packets in real time.

------------------------------------------------------------
APPLY FILTERS
------------------------------------------------------------

# Show DNS packets
dns

# Show TLS/HTTPS traffic
tls

# Show all traffic on HTTPS port
tcp.port == 443

# Show packets for a specific IP
ip.addr == <resolved_IP>

# Show plain HTTP traffic (for comparison)
http

------------------------------------------------------------
EXTRA ACTIONS
------------------------------------------------------------

1. Right-click on a TLS packet → Follow → TCP Stream  
   Observe encrypted data (to confirm TLS encryption).

2. Expand “Client Hello” and “Server Hello” packets  
   Note TLS version (for example, TLS 1.3), cipher suites, and certificate details.

3. Stop capture after a few minutes and save the file as:
   ChatGPT_capture.pcapng

------------------------------------------------------------
OPTIONAL NETWORK DISCOVERY
------------------------------------------------------------

Check your subnet:
   ifconfig

Discover live hosts (example for subnet 10.0.2.x):
   sudo nmap -p 80 10.0.2.0/24 -oG myscan.txt

------------------------------------------------------------
RESULT / OBSERVATION NOTES
------------------------------------------------------------

- DNS resolves chat.openai.com to Cloudflare IPs.
- TLS handshake is visible (TLS 1.3, encrypted payload).
- No plaintext data observed; traffic is protected by HTTPS.
- DNS queries may be visible unless DNS over HTTPS (DoH) is enabled.

CONCLUSION
------------------------------------------------------------

Wireshark successfully captured DNS, TCP, and TLS traffic.
ChatGPT communication was confirmed to be encrypted, with no plaintext leakage.

vulnerability assessment and packet analysis.
